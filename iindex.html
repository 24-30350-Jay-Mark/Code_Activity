My Projects

A collection of my recent works and applications

◀

E-Commerce Website

An online shopping website where users can browse products, add items to the cart, and proceed to checkout. The project focuses on creating a clean product layout and improving the user shopping experience.

Portfolio Website

A responsive portfolio website designed to showcase my skills, projects, and experience as a developer. The website includes sections like About Me, Skills, Projects, and Contact.

To-Do App

A productivity web application that helps users manage daily tasks efficiently. Users can add, edit, delete, and mark tasks as completed.

Movie Search App

A movie search web application that allows users to find movies and view detailed information such as ratings, release date, and posters using an external movie API.

Blog Website

A blogging platform where users can read articles and explore different topics. The website focuses on clean typography and content readability.

Tic Tac Toe Game

A simple interactive browser game where two players can play Tic Tac Toe. The project demonstrates JavaScript logic and user interaction.
